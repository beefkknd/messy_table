MessyTable · cross-view object re-identification

Is this the same object in another photo?

A step-by-step study using MessyTable, a labeled collection of everyday objects photographed by nine cameras at once.

  1. Part One · published

    Matching the same object across photos

    Given human object boxes, which box in one photo shows the same physical object in another? Two published matchers reproduced, 45 configurations compared.

  2. Part Two · published

    Teaching the system to find the objects

    Before matching, find the objects. A YOLO detector trained on human-labelled photos with close-up tiles now boxes 94% of objects on the full official test, up from 38% for the released model.
