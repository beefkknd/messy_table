Which objects are the same across these photos?

We want to identify the same physical item when different cameras see it from different angles, amid clutter and similar-looking objects. MessyTable gives us labeled scenes for testing this question.

For this stage, every method receives the same human-annotated object boxes. We compare how well the methods associate those objects across views. All models use frozen pretrained checkpoints.

The benchmark we kept

100 scenes from 100 different camera setups, 900 photos and 3,600 view pairs. We retain every pair among the nine cameras in each scene. The selection contains 30 easy, 50 medium and 20 hard scenes, chosen by a fixed hash rule.

There are 21,706 annotated object appearances and 78,335 true cross-view object pairs among 2,484,124 possible pairs. A positive match means the same physical item.

This is a 100-scene sample from the official test split. Our older 100-pair experiments have their own data selection and scoring settings.

What we are comparing against

ASNet represents the original appearance-and-surroundings approach. ViT-P3DE Tiny uses a transformer with learned camera and image-position information. The published full-test numbers provide context, and the runs on our fixed sample establish the controls for every variation below.

What was verified

The sample manifest and human boxes were retained exactly. Every configuration scored the same 2,484,124 candidates and 78,335 positives. The ASNet and ViT reference metrics reproduced the preceding sample runs exactly. The original metric functions and shipped native Linux matching solver ran in a pinned Python 3.7 environment. Crop and dense-feature caches were checked against the original inference paths.

All labels are supplied by the benchmark. Predictions and fixed scoring policies were saved before the sweep’s label-based metric evaluation. The selected winners represent performance on this benchmark, with generalization outside this sample still to be evaluated.
